## 本机地址发现

只读枚举进程路径、有限的常见安装目录、用户 `.dsh/profiles/*/node_modules/dsh-moments-agent`；便携安装仅检查已挂载盘根下少量命名目录，不递归扫描磁盘。不执行配置中的 YAML 标签、表达式或任何程序。

识别唯一已注册插件时，可推导其默认管理 API/令牌路径及 dataDir。已有客户端配置优先；配置文件不存在时才用于启动缺省值。设置卡可以重新检测并填入表单，保存仍需经过读回校验。运行中插件的已鉴权 `/api/environment` 提供真实包目录、数据目录、令牌文件路径和 Reader/Hook 配置；接口不返回令牌正文或微信账号。

本机实际文件发现：`D:\dsh\DeepSeek Harness.exe`、其 Python、`D:\wechatbot\app\WeChatAgent.exe`、已注册插件 `D:\dsh插插\dsh-moments-agent`、desktop profile 和 WeChatAgent Reader 配置。配置读取到 Reader 5031 / Hook 30001；这些结果证明文件发现和配置提取，不证明当前服务连通。WeChatAgent 的 OneBot WebSocket 端口不推断为 Hook 端口。

多个 profile 分别列出，不擅自选择。任意自定义安装目录、复杂动态 YAML 和非默认自定义 tokenFile/管理端口的离线推导不保证覆盖，可手填；已连通新版插件时以其运行值为准。

## 自适应定位

UIA 驱动继续按控件定位。Qt geometry 驱动新增当前截图内文字按钮精确匹配、区域约束、OCR word/line 重复合并、绿色复核和多候选拒绝。未知窗口按截图和当前窗口矩形换算屏幕物理坐标，支持副屏负坐标；点击前再读窗口矩形，移动/缩放则停止。焦点恢复后更新窗口矩形。已验证 1200×900、1342×971 且 100% 缩放保留原有几何路径。

EXE manifest 声明 PerMonitorV2；源码启动也尝试在 UI 创建前设置 DPI 感知。遵循 [Microsoft DPI 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setprocessdpiawarenesscontext) 推荐的 manifest 方式。

无文字相机图标并没有通用识别能力。未知布局下找不到唯一相机/编辑框提示/粘贴菜单就停止，不按比例盲点。只读诊断返回当前识别到的目标、窗口/截图大小、DPI 与缺失项，不导航、不输入、不发表。
