## 设置保存与刷新

- 客户端连接、人格、调度、表达技能均在保存后重新 GET 校验，读回不一致时报错，不显示保存成功。
- 刷新进行中再次点击会排队重新读取；保存期间手动刷新等待写入结束。旧请求不能覆盖保存后的界面。
- 自动轮询保留尚未保存的客户端配置、人格、调度和技能选项。顶部刷新明确重新读取服务器保存值，放弃当前未保存编辑。
- 请求超时覆盖响应正文读取，失败释放刷新锁，可以重试。
- 管理 API 地址与令牌路径热更新；内置执行器正在操作微信时拒绝切换连接。连接切换后执行器回到仅准备，需要重新同步所需发表模式。
- 内置执行器的数据目录变更持久保存，但须重启客户端才启用，界面明确提示。
