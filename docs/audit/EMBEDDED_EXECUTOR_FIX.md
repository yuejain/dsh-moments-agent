# 客户端内置桌面执行器修复

日期：2026-10-24（Asia/Singapore）

## 问题与修改

普通启动入口原先只运行 Web 客户端。Admin 入口分别启动客户端与执行器，且健康检查失败可能仍打印成功。现场旧执行器 `/health` 返回 `adminPrivilege=false`。

现在两个入口统一进入 `client/server.py`：在 Windows 启动时请求整个客户端的管理员权限，再在同一个 Python 进程的线程内运行执行器 HTTP 服务。客户端退出时释放两个监听端口。Windows 不支持原地提升已运行进程，所以 UAC 只用于重新启动整个客户端，不创建独立执行器服务进程。

保留默认 PREPARE_ONLY、令牌鉴权、账号核验与审批门禁。未配置账号时使用原有 UIA 核验方式，不能绕过账号校验。绑定失败会关闭客户端监听，返回非零状态；不会强杀端口占用者。隐藏启动日志保存在 `data/client-web.log`。兼容 PowerShell 写入的 UTF-8 BOM 配置与账号文件。
