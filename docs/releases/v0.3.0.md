# 插件 0.3.0 / 客户端 1.2.0 更新说明

发布日期：2026-10-25。配套升级 DSH 插件和 Windows 客户端。

## 本次发布解决什么

让首次使用者能完成本机配置，并让持续的人格、记忆、审核与调度串成可操作的自主表达流程。本次将仓库 0.2.1 之后的功能一起发布，包含首次启动自动配置、社交记忆、三级发表模式、自主调度、表达技能，以及微信 4.x 剪贴板和几何/DPI 修复。

## 主要变化

### 首次启动自动配置

客户端只读检测 DSH profile、插件注册/数据目录、WeChatAgent Reader/Hook 与令牌文件路径、掩码账号、模型 provider/model。预览将写入的配置，所有者确认后备份 profile 并原子替换目标插件条目，保留其他插件、注释和 `!!js`。成功后同步客户端连接，提示重载 DSH；失败可回退分步教程。

自动配置采用仅准备、不启用自主创作/发送、社交记忆和付费生图等保守默认值。它可能将旧 profile 中本插件的自动行为恢复为这些默认值，升级前应备份并核对预览。不会把令牌正文写入 YAML 或浏览器。

### 社交记忆与隐私门禁

显式开启后，只读白名单会话并提炼匿名人物印象，模型使用匿名别名，消息默认保留 30 天、印象 90 天过期，支持清除会话。私聊需单独开启。草稿含真实昵称或达到门槛的聊天原文片段时会被拒绝。SQLite 自动迁移到 v3，正常升级无需清空数据库；升级前应完整备份数据目录。

新增 3 个社交记忆工具，总工具数 20，并增加相应管理接口及设置卡片。细节见 [社交记忆](../architecture/chat-memory.md)。

### 发表模式、调度与表达

三级选项为仅准备、审批后发表、免逐条审批发表；自主创作与自动发送分别控制。免审批仍要求审核通过、快照一致及账号/额度/时段/暂停/Kill Switch 等门禁。点击结果不确定时进入 `UNCERTAIN`，不自动重发。

增加可分别启用的 Lieflat 去 AI 味与朋友圈自然表达；在后续创作、审核的原请求内使用，不执行上游脚本、不额外调用模型。修复设置保存读回、刷新排队、超时和表单缓存保护。

### 微信 4.x 桌面链路

固定主窗口为 **1200×900 物理像素**，修正早期逻辑尺寸在 150% DPI 下扩大为 1800×1350 导致点位偏移的问题。窗口、鼠标与截图使用 Per-Monitor-V2 物理像素语义。

编辑器和右键菜单使用屏幕捕获，并检查前台窗口属于微信进程。剪贴板使用正确的 64 位 WinAPI 句柄、重试与清理逻辑；继续通过 OCR 读回正文、按钮颜色和发布后核验判断结果。窗口变化、遮挡、内容不一致或无法确认时停止。

独立 Python 执行器支持与未提权微信进行同完整性输入；Windows EXE 声明管理员权限，管理客户端和桌面执行器仍在同一进程内。

## 下载及升级

发布页提供：

- `DSH-Moments-Client-1.2.0-win64-exe.zip`
- `dsh-moments-agent-0.3.0.tgz`
- `DSH-Moments-Client-1.2.0-SHA256SUMS.txt`
- 对应 `-verification.json` 与 `-signature.json`

升级步骤：

1. 暂停当前自动行为并退出旧客户端/旧独立执行器，保留用户数据和配置。
2. 在无运行任务时备份数据目录与 DSH profile；不要用新包覆盖数据库、令牌或账号文件。
3. 将插件 TGZ 解压，在 DSH 中从解压后的 `package` 目录安装/升级，并重载插件。
4. 将 EXE ZIP 完整解压到可写目录，保留 `_internal`。首次自动配置如需写入，请先检查预览与备份位置。
5. 确认客户端和插件使用同一 dataDir/令牌文件。自动配置之后重新核对原发表模式、调度和记忆设置；按提示重载插件或重启客户端。
6. 从仅准备的纯文字演练开始，完成账号、模型、Reader/Hook、剪贴板、OCR 和窗口检查后，再恢复所需发表模式与调度。

说明：[EXE 使用](../EXE-RELEASE.md)、[自动配置](../operations/AUTO_SETUP.md)、[故障排查](../operations/TROUBLESHOOTING.md)。

## 验证结果与限制

本次发布复核使用 Node 和 Python 3.12：Node 242 项中 241 通过、1 跳过；执行器 271 项中 268 通过、3 跳过；客户端 177 项全部通过，总计 **686 通过、4 跳过**。Mock 插件 20 工具注册、健康/状态、数据库与保守发表策略自检通过。跳过项与宿主依赖/权限有关，不将跳过视为已验证。

EXE/ZIP/TGZ 静态核验包含：归档 CRC、文件与源码一致性、内嵌 Python 模块、管理员/PerMonitorV2 manifest、凭据/数据库/原始现场记录排除、SHA256 和签名完整性。使用本地自签名证书和 DigiCert 时间戳；不会自动成为其他电脑受信任的发布者，私钥不随包分发。

此前一次真实自动发表验收使用 1.1.9 修复链路、独立 Python 执行器、微信 4.1.10.27 和 150% DPI，完成调度、准备、点击与 OCR 核验。**1.2.0 EXE 本次未做 UAC 实机启动和真实发表验收**；其他微信版本、主题、显示器组合，真实删除/回滚、微信通知及订阅生图仍需验证。

公开源码与插件不包含原始现场截图/日志、真实账号、令牌、数据库或聊天记录。既有公开验收说明已脱敏；完整原始材料保留在本机。
