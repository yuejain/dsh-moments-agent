# 插件 0.3.2 / Windows 客户端 1.2.3

## 更新内容

- 修复桌面执行器连接、令牌路径和状态诊断；客户端内新增连接卡片，验证成功后持久化。
- 分离 Reader/Hook 登录账号核验与微信审批接收人配置；账号不一致或读取失败仍禁止发表。
- 首次配置精简为六步，环境自检和常见问题移至概览。可保留已有设置并完成首次配置。
- 直接发表期间展示等待状态并阻止重复点击。

## 升级

1. 停止旧客户端，安装并重载 DSH 插件 0.3.2。
2. 完整解压 1.2.3 EXE 便携包；保留原客户端目录中的 client/moments-client.json 和 client/setup-state.json，按需复制到新包的 client 目录，以保留连接与首次配置进度。
3. 启动 EXE，允许管理员启动；在概览检查账号、OCR、桌面执行器及发布模式。若插件未连接，在设置中验证并启用桌面执行器连接。
4. 检查已有调度、待发布队列与模式；恢复连接可能使已有符合条件的任务继续执行。

## 验证及限制

- 本机使用客户端 1.2.2 / 插件 0.3.2 完成一次真实纯文字朋友圈发表，任务 PUBLISHED、尝试 VERIFIED，OCR 与截图核对成功。首次配置完成与重启未再弹窗也在该版本实测。
- 客户端 1.2.3 增加发表等待提示；该更改通过自动化测试，尚未完成相同的真实发表与重启测试。发布间隔策略未改动。
- 微信版本、界面、桌面焦点和 OCR 会影响结果；点击不等于发表成功，结果不确定时不要自动重发。
- EXE 以本地自签名证书签名并带时间戳；该证书不会自动受其他 Windows 设备信任。
